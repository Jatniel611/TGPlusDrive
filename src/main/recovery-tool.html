    ¿Cómo funciona? Cada parte se llama Nombre.ext.part-000000000000. El número final es la posición en bytes, así que el orden alfabético ya es el orden correcto. Esta página une los archivos tal cual, sin recomprimir nada, y el resultado es idéntico al original.
    Alternativa con comandos (sin esta página) Windows (en la carpeta de las partes): copy /b Nombre.ext.part-* Nombre.ext Linux / macOS: cat Nombre.ext.part-* > Nombre.ext
